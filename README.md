# Operations Intelligence

Enterprise intelligent automation platform built on ServiceNow.
Enables governed, conversational automation across organisational groups
through natural language interaction, role-based access, and structured
approval workflows.

## Interfaces

| Name | Purpose | Audience |
|---|---|---|
| Operations Command | System administration and full platform control | Admins |
| Operations Governance | Group management, user onboarding, approvals | Leadership |
| Operations Studio | Automation design and management | Creators |
| Operations Workspace | Browse and trigger automations | Users |
| Operations Assistant | Conversational AI layer across all interfaces | Everyone |
